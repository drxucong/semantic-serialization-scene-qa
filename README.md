# Semantic Serialization Scene-QA — Evaluation Release

Public evidence package for the paper:

> **Semantic Serialization as a Perception Interface for Small Language Models in
> Closed-Set, Task-Aware Embodied Question Answering**
> Cong Xu and Ravi Sankar, iCONS Lab, Department of Electrical and
> Computer Engineering, University of South Florida. *IEEE Access, resubmission of
> Access-2026-44226 (first submitted as "Free the Language Model From the Vision
> Encoder: Semantic Serialization as a Perception Interface for Small Language Models").*

This repository contains what is needed to **recompute the accuracies and intervals that
the paper reports for the confirmatory bank** — question banks, per-question prediction
logs for every evaluation arm, the perceived-state files the serializer consumed, the
documents that fix the criterion, and the statistical analysis scripts — without
redistributing the system implementation. Time, memory, and power measurements are
released as logs.

**For the revised manuscript, start with [`SUPPLEMENT.pdf`](SUPPLEMENT.pdf) and
[`exp_rev1/README.md`](exp_rev1/README.md).** `SUPPLEMENT.pdf` is the Supplement that the
revised manuscript refers to (Sections S1 to S18). `exp_rev1/README.md` maps
every folder of the revision to a section and table and names the two scripts that
recompute the numbers. [`SUPPLEMENT.md`](SUPPLEMENT.md) is the map of the material that
accompanied the first submission; its section and table numbers refer to that version.

## What is here

| directory | contents |
|---|---|
| `banks/` | the four question banks: development (`qa_coda.jsonl`, 1366 items), confirmatory (`qa_confirm.jsonl`, 1328), and the frozen probe banks `n1_bank.jsonl` (paraphrase) and `n2_bank.jsonl` (novel judgment) |
| `states/` | ground-truth object states (`states_coda.json`) and the perception stack's output states, per bank and system version (v8 = the tied system, v9 = shipped; `*_nostereo` = the −stereo ablation). Each record: class, distance, bearing, image column, confidence flag per object — the exact input the serializer saw |
| `results/` | per-item prediction logs for **every arm in the paper** (`phase10/` development-era arms incl. the 2×2, ladder, controls, oracles, repeats; `exp1_infer/` D-ladder + N1/N2; `exp2_infer/` reader-scale sweep; `exp3_infer/` current-generation, blind, FT arms; plus baseline and prediction CSVs). Fields are predictions and scoring only — no prompts |
| `summaries/` | the frozen result summaries the manuscript quotes (A3/A4/A5 contrast tables, baselines, compute measurements, per-family tables) |
| `amendments/` | the pre-registration evidence chain: amendments A3–A5 with their addenda, the N1/N2 schema, and the D-ladder specification, all written before the runs they govern |
| `analysis/` | the statistics and audit scripts: cluster-bootstrap contrasts, bank-composition and near-duplication audits, repeat-run analysis, rule-fix and arg-min audits, and the re-attribution script |
| `exemplars/` | five real serialized-state texts (one per question family), generated by the shipped serializer from confirmatory-bank perceived states, shown next to their questions |
| `exp_rev1/` | everything added for the resubmission (IEEE Access-2026-44226): VLM-aid arms, scene-graph formats, detector swap, lighter stacks, edge boards (Orange Pi 3B, Agilex 5 HPS, Jetson Orin Nano), nuScenes external evaluation, detector generalization, payload and memory, with the analysis scripts that recompute the numbers of the revised manuscript; see `exp_rev1/README.md` |

## Reproducing the headline numbers

Every accuracy and paired difference on the confirmatory bank can be recomputed from
`results/`, `exp_rev1/`, and `banks/` (`python exp_rev1/analysis/rev2_analysis.py`). For
example, the two primary comparisons (Section VII-A of the revised manuscript):

```python
import json, glob
def acc(d):
    rows = [json.loads(l) for f in glob.glob(f"results/phase10/{d}/*.jsonl") for l in open(f)]
    return sum(r["correct"] for r in rows) / len(rows)
print(acc("results_cf_v15_7b"), acc("results_cf_px_7b"))   # 0.7892  0.7462
print(acc("results_cf_v15_3b"), acc("results_cf_px3b_robust"))  # 0.7673  0.6913
```

Cluster-bootstrap confidence intervals: see `analysis/confirm_analysis.py`
(21 sequence clusters, B=20000, percentile CIs; the seed is recorded in the summaries).
The source of the serializer is in [`serializer/`](serializer/README.md), with a script that
checks it against the released logs. Its compiled-field behaviour can also be audited via
`analysis/v10_argmin_audit.py`, `analysis/v12_rule_fix.py`, `analysis/check_sector.py`,
and `analysis/reattribute.py`, all of which run directly on `states/` + `banks/` +
`results/`.

## What is deliberately not here

The perception-stack implementation, the fine-tuned detector weights, and the
question-bank generators are not distributed. The source of the serializer was added on
2026-11-15 (`serializer/`). The revised paper describes them (Sections IV and V); trained detector weights are available from the authors on reasonable
request. Images are not redistributed: obtain CODa from its official page and the
`cam_front` paths in the banks resolve against it.
