# B1–B3 pre-registration (declared 2026-10-14, before any run)

Purpose: answer R1-1 / R2-3 / R3 (fairness of the zero-shot pixel baseline) by giving the
VLM, one ingredient at a time, what the serialized system has. Confirmatory bank
(`outputs/coda/qa_confirm.jsonl`, 1328 items), forced track, clean protocol, same
system prompt / option format / T=0 / 8 tokens / parser as the shipped pixel arm
(`scripts/pilot/run_pilot_pixel_ollama.py`). Models: `qwen2.5vl:3b`, `qwen2.5vl:7b`
(ollama, same tags as the archived runs).

Arms (script `scripts/rev1/b123_vlm_aids.py`):
- `pixel`    control re-run (same-machine pairing check; expected |Δ| ≤ 0.0015 vs archived PIXEL_3b/7b).
- `stereo`   B1: cam0 + cam1 as two images.
- `taskinfo` B2: cam0 + decision vocabulary (bands 5/15 m, ±15° sectors, 40 m scope, family hint).
- `hybrid`   B3: cam0 + the shipped Scoped serialized state (regenerated byte-identically).

Analysis (fixed): paired difference vs the archived pixel arm on the same items, 21-sequence
paired cluster bootstrap, B = 20000, seed 20260809, percentile CI; `*` iff CI excludes zero.
Also report each arm vs the serialized system (D0_3b / D0_7b). Unparsed counted as wrong;
parse rate reported. All three arms are **exploratory** (post-hoc to the frozen criterion)
and will be labelled so in the paper.

Predictions written down before running (so we cannot move the goalposts):
- B1 stereo: small or null change (VLMs are not known to triangulate from two views); if it
  resolves positive, the stereo cue is part of the sensor story and we say so.
- B2 taskinfo: positive at 7B is plausible (nearest-distance band definition); counting
  unlikely to move. If B2 closes the gap to D0, the "task-aware" framing of the serializer
  becomes the main explanation and we say so.
- B3 hybrid: expected ≥ pixel; the interesting comparison is hybrid vs D0 (does seeing the
  image on top of the text help or hurt a reader of the same scale?). VL-on-text (text only,
  VLM weights) is already in the paper at +0.0377 / +0.0949.

No arm will be dropped after seeing its result; all four go in the paper or supplement.
